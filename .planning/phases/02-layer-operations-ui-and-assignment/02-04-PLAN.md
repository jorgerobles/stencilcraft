<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| control/MCP command JSON → LayerAddMembers/LayerRemoveMembers/LayerSetOperation | Untrusted indices/ids/operations cross here. |
| pointer drag payload (OpDrag) → panel drop hit-test | Drag payloads are untrusted; must not be confused with list reorder payloads. |
| context menu construction from document state | Menu entries are built from doc.layers; indices must stay valid until dispatch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-11 | Spoofing | OpDrag palette payload vs ListDrag reorder payload | medium | mitigate | Distinct `OpDrag` payload type; drop hit-test only accepts layer-row rects from the current frame's `ListOutput.rows`; shape/Unassigned rows ignored. |
| T-02-12 | Tampering | menu-assigned layer index between render and dispatch | medium | mitigate | Commands re-validate via `layer_index`/`editable_ids` inside `DocumentCommand::run()`; a stale index returns `EngineError::Invalid`, never panics. |
| T-02-13 | Elevation of privilege (local) | assignment to a locked layer via menu | high | mitigate | Apply arms reject locked targets (02-02 behaviour, re-asserted by tests); menu entries for locked layers are disabled. |
| T-02-14 | Tampering | hostile document feeding the Send to Layer… submenu | medium | mitigate | Submenu lists only `doc.layers` entries with valid indices; layer count capped by document validation on load. |
| T-02-SC | Tampering | cargo git dependencies | high | mitigate | No dependency changes in this plan. |
</threat_model>
