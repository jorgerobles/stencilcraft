<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.stencilcraft` file → document loader → panel/paint | Untrusted persisted content (dangling member ids, duplicate ids, non-finite geometry) is rendered by these helpers. |
| control/MCP command JSON → engine → derived views | Command params cross here; views must never trust indices/ids without the engine's validation. |
| drag/drop payloads → panel hit-testing | Pointer payloads are untrusted; only known row rects are hit-tested. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Tampering | `build_layer_rows`/`pass_number`/`effective_operation` over hostile documents | high | mitigate | Resolve every member id through `doc.get_shape` (dangling ids skipped, never indexed with `[]`); cap row counts; no unwrap outside tests. |
| T-02-08 | Tampering | `layer.color` string → paint | medium | mitigate | `parse_hex_color` returns Option; unparseable colour falls back to the operation token, never panics. |
| T-02-09 | Spoofing | drag payload vs List reorder payload confusion | medium | mitigate | Only `ListOutput.rows` rects of the current frame are hit-tested; foreign payloads are ignored until 02-04 introduces `OpDrag`. |
| T-02-10 | Information disclosure | derived Unassigned group | low | accept | It is computed per frame and never persisted or exported; local desktop app. |
| T-02-SC | Tampering | cargo git dependencies | high | mitigate | No dependency changes in this plan; pins stay as 02-01 set them. |
</threat_model>
