## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| colour picker / swatch input → LayerSetColor | Free-form colour strings cross here. |
| drag-reorder gesture → LayerMove params | Pointer-derived from/to indices are untrusted until revalidated. |
| control/MCP command JSON → LayerMove/LayerSetColor/LayerSetVisible/LayerSetLocked | Untrusted command params cross here. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-15 | Tampering | colour string from picker or command JSON | medium | mitigate | `parse_hex_color` + `format_hex_color` canonicalisation in the engine arm; invalid input returns `EngineError::Invalid`; UI never dispatches unparseable strings. |
| T-02-16 | Tampering | reorder from/to indices | medium | mitigate | `layer_index` bounds-check inside `DocumentCommand::run()`; accepts closure restricts moves to layer rows only; no `[]` indexing. |
| T-02-17 | Elevation of privilege (local) | property edits on a locked layer via panel or MCP | high | mitigate | Locked-layer rejection in the apply arms (02-02); panel disables the row controls when `layer.locked`. |
| T-02-18 | Denial of service | hostile document with huge layer count driving per-frame Pass N | low | accept | Row counts capped by document validation on load; Pass N is an O(n) enumeration per frame over a validated document. |
| T-02-SC | Tampering | cargo git dependencies | high | mitigate | No dependency changes in this plan. |
