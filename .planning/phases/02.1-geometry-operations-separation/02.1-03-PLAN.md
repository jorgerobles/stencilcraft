<objective>
Make the UI show geometry as geometry and operations as operations, reading the first-class `Document.operations` directly. The hammer and bulk actions create operations over the untouched tree.
</objective>

<tasks>

1. Build the **Geometry** panel from `doc.groups` (recursive `GroupChild`), plus the Unassigned shapes leaf list. Double-click enters a group; click selects; shift/marquee deep-select. Wire group/ungroup to `GroupCreate`/`GroupUngroup`.
2. Build the **Operations** panel from `doc.operations`: icon, derived `pass_number`, colour swatch, profile (`OperationSettings`), member count. Hammer on a row creates an operation from that layer; hammer on a geometry node/selection creates one scoped to it.
3. Add operation tags on geometry rows: `{id} {colour}` chips, `…` overflow (remove membership, toggle visibility, select members). Add a view-only filter that hides shapes whose only/selected operations are filtered out.
4. Add the bulk menu: "New operation by colour", "New operation: all selected", "New operation: each selected". Count affected shapes; if `count > UserPrefs.bulk_confirm_threshold` show "Create N operations? Continue?".
5. Add e2e coverage in `mod ui_e2e`: import a nested fixture → groups visible; hammer → operation appears and membership lands; bulk-over-threshold → confirm gate; filter hides geometry.

</tasks>
