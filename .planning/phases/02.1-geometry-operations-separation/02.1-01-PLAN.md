<objective>
Make "geometry loaded from the source is untouched" true: nesting becomes groups, style becomes hints, and the old semantics remain reachable behind a preference.
</objective>

<tasks>

1. Write `docs/adr/0001-geometry-preserving-import.md` (Status: Accepted). Record: `<g>` → `Group`, style → hints, legacy flag, test changes, and that operation assignment is a user action.
2. In `crates/svg/src/lib.rs` change `import`/`import_with_warnings` to build `doc.groups` for `<g>` (recursive `GroupChild::Shape`/`GroupChild::Group`) while keeping shape-id allocation and transform inheritance. `doc.layers` stays empty for a plain import (all shapes start Unassigned).
3. Add `operation_hints: Vec<OperationHint>` to `SvgImport` (`group` path/name + suggested `Operation` from `data-kind`/class). Do not apply them.
4. Add `UserPrefs.import_legacy_style_operations: bool` (`#[serde(default)]`, false) and branch to the old layer-building path when set.
5. Surface hints in the app as a dismissible "Apply N operation hints?" affordance that dispatches normal operation commands on confirm (no import-time writes).

</tasks>
