<objective>
Add the derived model behavior and delete semantics on top of the proven v2 skeleton: unassigned-shape derivation, ordered production sequence, layer deletion that preserves geometry, membership pruning on load, and operation-parameter validation. Prove each with integration tests including multi-layer membership and all operation variants.

Purpose: These are the user-visible semantics that make operation layers safe to edit — an unassigned shape stays valid, deleting a layer never destroys geometry, and a malformed membership list cannot corrupt the document.
Output: Derived query methods, delete/prune/validate hardening, and integration tests for derived behavior, operations, and canvas over membership.
</objective>
