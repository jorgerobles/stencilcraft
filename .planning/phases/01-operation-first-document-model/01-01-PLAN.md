## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file → wire_v1 / DocumentFields | Untrusted JSON from a `.stencilcraft` file crosses into deserialization here |
| document → save_json | Model values are serialized back out; malformed in-memory values must be rejected before writing |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-01 | Tampering | wire_v1 / load_json_named | high | mitigate | Deserialize-only v1 mirrors; malformed input maps to `DocError::Parse`/`Structure`; the format crate denies `panic`/`unwrap`/`expect` and the document crate's non-test code returns `Result` (hostile coverage lands in 01-04), so hostile JSON cannot abort the process |
| T-1-02 | Denial of Service | V1SourceGroup recursion | low | accept | Recursion is bounded by the parsed input size and `serde_json`'s depth limit; no unbounded allocation beyond the input |
| T-1-03 | Tampering | Document.shapes + Layer.members | high | mitigate | Geometry stored once and referenced by id; load validation rejects duplicate ids, and 01-03 prunes dangling members before validation so a stale id cannot survive |
| T-1-SC | Tampering | cargo dependencies | low | accept | No new dependencies are added in this phase |

## Severity Scale

- critical: remote code execution, data loss, or full model corruption on untrusted input
- high: panic/abort or silent data loss on a malformed but plausible file
- medium: recoverable error surfaced with a wrong message
- low: requires an already-compromised local environment
</threat_model>
